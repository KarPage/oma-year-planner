# Screenshots

Release screenshots live in the repository root, in [screenshots/](../../screenshots/). The root README shows them. This folder does not hold the image files.

- `hero.png` is the full board: pinned day numbers, Upcoming and Last, past months dimmed, and thin bars that wrap from one month into the next. `preview.png` at the repository root is that same shot, for the marketplace.
- `window.png` is the planner in a floating window: Next and Up next on one row, Last as one muted line, and search as an icon.
- `add-plan.png` is the quick add popover, including Attach photo.
- `plan-photo.png` is a plan opened on the board, with its note and a photo.
